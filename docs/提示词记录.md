# AI 提示词与开发记录

在本次开发中，我大量使用了 AI 工具（如 ChatGPT、DeepSeek 等）来辅助写代码和排查 Bug。以下是我在开发过程中比较有代表性的提问和解决过程记录。

## 一、 初始架构与设计
- **我**：“我想做一个求职/兼职信息聚合分析的小型爬虫软件，打算用 Flask + SQLite，你能帮我梳理一下项目需要分几个文件，数据库表怎么建吗？”
- **AI 协助**：建议我分为 `app.py`（路由）、`database.py`（数据库操作）、`spider.py`（爬虫）三个文件，并给出了包含 ID、标题、公司、薪资等字段的建表 SQL 语句。这帮我确立了一个很清晰的开发框架。

## 二、 爬虫抓取与数据逻辑
### 1. 为什么每次抓取都只有 30 条？
- **我**：“我每次点抓取，虽然提示成功了，但网页上的总数一直停留在 30 条，这是为什么？我想实现每次点一下，就抓取 30 条‘全新’的数据，叠加到 60、90，应该怎么改？”
- **AI 协助**：AI 告诉我 GitHub 接口默认一次只返回一页（30条），并且我之前写了去重逻辑，所以旧数据不会再进来。在 AI 的指导下，我增加了一个记录页码的配置表，每次抓取完自动让页码 `+1`，成功实现了数据量的不断叠加。

### 2. 抓取速度太慢，怎么优化？
- **我**：“因为我要调用翻译接口把英文标题转成中文，现在抓取 30 条要等二三十秒，太慢了，有没有办法快点？”
- **AI 协助**：AI 建议我引入多线程并发（`ThreadPoolExecutor`）。我把原来的单线程 `for` 循环改成了并发请求，原本要等 30 秒的抓取，瞬间降到了 3 秒左右，速度直接起飞。

### 3. 为什么提示“未抓到新数据”？
- **我**：“我连续点了几次抓取后，突然提示‘未抓到新数据，或网络受限’，是不是我的程序坏了？”
- **AI 协助**：AI 解释说这是 GitHub 官方接口的限流机制（Rate Limit），连续高频请求会被拦截。AI 建议我在代码外层加上 `try...except`，如果被拦截，不要直接报错崩溃，而是给前端弹出一个友好的绿色提示语。这让我学会了在写爬虫时一定要考虑异常兜底。

## 三、 界面美化与图表优化
### 1. 图表上的字太丑了，全挤在一起
- **我**：“我用 ECharts 画了饼图，但是抓下来的公司名全是又长又臭的英文（比如 literally-everything...），标签全叠在一起看不清，怎么办？”
- **AI 协助**：AI 给了我三个很实用的前端思路：先按数量从大到小排序，只截取前 10 名显示；对于超长的英文，用 JS 写一个截断功能（超过 15 个字母就用 `...` 代替）；最后，在前端手写一个中英字典映射，把长串的英文换成了‘初创CTO必备指南’这种好懂的中文。

### 2. 界面太简陋，想要高级感
- **我**：“现在的 HTML 页面太丑了，像个学生作业。能参考 Crawlab 那种后台管理系统，帮我写一套带左侧深色导航栏、顶部面包屑、卡片式布局的现代化界面吗？”
- **AI 协助**：AI 帮我重新写了一套完整的 CSS。换上之后，整个系统瞬间变成了企业级的后台管理面板，布局也清晰多了，看起来非常专业。

## 四、 导出功能迭代
- **我**：“原本我用的 CSV 导出，但长标题和 URL 用 Excel 打开时会挤在一起，完全没法看。能帮我改成原生的 Excel 格式吗？最好带点格式。”
- **AI 协助**：AI 让我安装了 `openpyxl` 库，并帮我重写了导出路由。通过设置字体为微软雅黑、给表头加上蓝色背景高亮，以及开启自动换行，现在导出来的表格排版非常完美，看起来跟正规公司的报表一样。

## 五、 真实 Bug 修复记录
- **问题 1**：前后端连通报错。我点击删除按钮时，网页报了 `AttributeError`，说找不到 `delete_job`。
  - **解决**：我把报错发给 AI，AI 帮我检查代码后发现，是我新建函数时，不小心把函数缩进到了 `if __name__ == '__main__':` 里面，导致外部无法调用。退格对齐之后解决了。
- **问题 2**：依赖缺失报错。换电脑或者重新运行环境时，系统提示 `ModuleNotFoundError: No module named 'flask'`。
  - **解决**：AI 提醒我需要先安装依赖。我学会了使用 `pip install -r requirements.txt`，并且在添加了 `openpyxl` 库之后，重新用 `pip freeze > requirements.txt` 更新了依赖清单，确保别人下载我的代码也能跑起来。
